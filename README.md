## 搬瓦工 KVM 到底是什么

KVM 是 Linux 内核中的虚拟化技术，全称是 Kernel-based Virtual Machine。简单理解，它让 VPS 运行在更接近独立虚拟机的环境中，而不是和宿主机共用同一个系统内核。

搬瓦工官网明确说明，其 VPS 服务运行在 KVM 虚拟化平台上，并通过自研的 KiwiVM 控制面板管理。用户可以进行开关机、重装系统、使用紧急控制台、设置反向 DNS、迁移数据中心、创建快照和查看流量统计。

这对实际使用有几个影响：

1. **可以获得完整 root 权限。**
   你可以自行安装 Nginx、Docker、WireGuard、面板、数据库或其他 Linux 软件。

2. **系统选择更自由。**
   官网目前列出了 AlmaLinux、RockyLinux、CentOS、Debian、Ubuntu、CentOS Stream 和 Fedora，同时支持更多可启动 ISO。

3. **需要自己负责服务器管理。**
   搬瓦工属于 self-managed VPS。系统更新、防火墙、SSH 安全、网站配置、备份和应用故障，主要都由用户处理。低价的背后没有托管运维团队替你配置每一个服务。

所以，搬瓦工 KVM 更像是一台放在机房里的 Linux 云服务器，而不是开箱即用的虚拟主机。

## 普通 KVM 和 CN2 GIA 有什么区别

很多中文用户搜索搬瓦工 KVM，其实真正关注的是中国大陆访问速度。这里要把两个概念分开：

- **KVM** 解决的是虚拟化和服务器资源环境问题。
- **CN2 GIA、CTGNet、CMIN2 等线路** 解决的是网络路径和跨境访问质量问题。

一台 KVM VPS 不等于一定拥有优秀的中国访问线路。即使 CPU、内存和硬盘配置完全相同，不同数据中心到中国大陆的延迟、丢包和晚高峰表现也可能不同。

搬瓦工官方对 CN2 GIA 的说明显示，普通 IP Transit 在高峰时段可能出现拥堵，而 CN2 GIA 的定位是改善中国方向的网络稳定性。官方同时提醒，CN2 GIA 成本高、容量有限，遇到 DDoS 攻击时可能采取 IP nullrouting，也就是临时阻断受到攻击的 IP。

洛杉矶 USCA_9 是官方重点介绍的线路节点之一。官网称，该位置同时接入 China Telecom CN2 GIA、China Mobile CMIN2 和 China Unicom Premium，并提供美国本地互联。

因此，选择时可以按下面的方式判断：

| 你的主要需求 | 更适合的方向 |
| --- | --- |
| 面向美国或欧洲用户的网站 | 普通 KVM 即可 |
| 个人博客、学习和测试 | 20G 或 40G 基础 KVM |
| 需要更多内存运行 Docker 和数据库 | 80G 或 160G |
| 用户主要在中国大陆 | 优先查看 E-Commerce / CN2 GIA 方案 |
| 跨境电商、在线业务、远程办公 | 重点比较线路、流量和节点，而不只是 CPU |
| 经常遭受攻击的服务 | 仔细阅读 DDoS、nullrouting 和 SLA 条款 |

## USCA_9 E-Commerce 方案应该怎么看

提供的 AFF 链接会进入洛杉矶 USCA_9 的 E-Commerce 订单路径。这个产品系列的重点不是单纯增加内存，而是提供面向中国方向的优化线路。

官方页面将 E-Commerce 方案与 CN2 GIA、CTGNet 线路联系在一起，并说明 USCA_9 还使用 CMIN2 和 China Unicom Premium 路由。

选这类方案时，建议重点看四项：

1. **月流量是否够用**
   网页访问、图片、下载、视频和 API 请求会快速消耗流量。1 TB 与 3 TB 的差别，往往比多一两个 CPU 核心更实际。

2. **端口速率和实际线路表现**
   2.5 Gbps 或 5 Gbps 是端口上限，不代表任何时段、任何方向都能跑满。中国方向的体验还取决于运营商和具体路由。

3. **是否需要中国方向低丢包**
   如果用户主要在北美，CN2 GIA 的溢价可能没有必要。线路优势只有在目标访问方向确实存在时才有价值。

4. **是否接受自主管理**
   E-Commerce 仍然是 VPS，不会因为线路更贵就自动变成托管服务器。系统安全和应用维护依旧由用户负责。

## KiwiVM 能做什么

KiwiVM 是搬瓦工自研的 VPS 管理面板。官网列出的功能包括：

- 启动和关闭 VPS
- 重装操作系统
- 紧急控制台
- 设置 PTR / rDNS
- 数据中心迁移
- 创建和管理快照
- 查看用量统计
- API 管理
- VPN 所需的 tun/tap 支持

这些功能对自主管理 VPS 很实用。尤其是重装系统、紧急控制台和数据中心迁移，可以减少服务器配置出问题时的处理成本。官网还提供即时部署、99.9% uptime guarantee 和 30 天退款政策，但具体资格仍需以对应方案的条款为准。

不要把快照当成完整备份。快照主要用于快速回滚，数据库、网站文件和重要配置仍然应该定期导出到独立位置。服务器和备份放在同一处，遇到节点故障时就会比较被动。
